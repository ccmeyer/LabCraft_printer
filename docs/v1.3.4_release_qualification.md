changes into main and preparing an application release. Feature commit

The release branch adds only VERSION, changelog, release-index/manifest metadata

The call path is PlateReaderAnalysisWindow -> preview/worker -> offline

## Operator behavior

Tecan Infinite i-control XLSX imports support kinetic tables and endpoint
grids. The worksheet chooser requires an explicit acquisition when several
measurement sheets exist. Fractional times, channel, gain and temperatures are
preserved. Saturated, missing, formula-based and nonnumeric readings are refused
with measurement context. Gains remain separate; RFU normalization is not added.
Existing tab-delimited XLS/TXT imports remain supported.

Grouping & Exclusions proposes declared experiment-design concentrations unless
a saved experiment settings document exists. Each keyed calculated value must
match exactly one intended level within the visible tolerance, initially 2%.
Zero targets accept only numerical zero. Unknown, ambiguous or out-of-tolerance
levels block analysis. Unlisted reagents keep their exact calculated values.
Signals and original concentration keys are never rounded or rewritten.

Manual exclusions require measured wells and reasons. They apply across all
times and channels before analytical statistics, outlier baselines and plots,
including both statistical-outlier plot variants. Raw measurements, calculated
and intended concentrations, reasons, settings and separate excluded-well QC
remain in reports and ZIP exports. The experiment sidecar is validated and
atomically replaced with a concurrent-write check; invalid or future-schema
documents are not overwritten. Preview is read-only.

Some supplied conditions retain only two replicates after N1:P4 is excluded;
replicate-based endpoint outlier detection requires at least three. Empty
conditions are reported, and excluding every usable keyed well is refused.
These analysis choices remain editable and should be rerun into a fresh output
directory to preserve previous results.
