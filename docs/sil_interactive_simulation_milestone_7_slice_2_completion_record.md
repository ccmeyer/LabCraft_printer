## Implemented Architecture

- `ExperimentEditorDriver` accepts a validated ordered reagent sequence while
  preserving the one-reagent compatibility path.
- `RackDriver` locates a unique stock slot and performs bounded UI unloads.
- `ArrayDriver` accepts an explicit expected dialog sequence for repeated
  starts.
- `ExecutionObserver` owns bounded intent, progress, durable-I/O, pass, and
  history observation and restores all installed hooks on success or failure.
- Reusable read-only assertions validate head exchange, settings, pass
  boundaries, completions, starvation, intent durability, bounded histories,
  terminal persistence, artifacts, and cleanup.
- `ComposedReportAdapter` supplies the common smoke, editor, and multi-stock
  report envelope.
- The capability manifest now reports the scenario's real UI/model/harness
  surfaces and modern retained artifacts.
