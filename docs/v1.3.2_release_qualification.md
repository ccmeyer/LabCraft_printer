and three reviewed legacy cohorts remain unchanged. Stable manifests retain
schema v1 and explicitly authorize only v1.2.0-rc.6, v1.2.0 and v1.3.0-rc.1.

firmware/recovery verification and attended canary procedure.

campaign qualifies v1.3.1 as a fallback merely because capabilities match.

protected current-version or exactly qualified compatible-bundle recovery.

Validate tags, merge the reviewed release PR into main with the exact tagged
tree, and advance stable only if its current tip is an ancestor of the tagged
revision. Verify public refs and read the public stable index after publication.
